# Руководство пользователя Ostatki

Приложение считает по ведомости остатков ТМЦ (выгрузка 1С): прибыльность, сезонность спроса и
столбец **«К закупке»** — сколько единиц каждого товара заказать, чтобы хватило на выбранный период.

## Запуск

1. Скачайте `Ostatki-windows-amd64.zip` со страницы Actions/Release репозитория и распакуйте.
2. Запустите **Ostatki.exe**. Откроется консольное окно (не закрывайте его во время работы)
   и вкладка браузера с интерфейсом. Если браузер не открылся — в консоли указан адрес вида
   `http://127.0.0.1:8765/`, откройте его вручную.
3. Windows SmartScreen может предупредить о неизвестном издателе (exe без подписи) —
   «Подробнее» → «Выполнить в любом случае».
4. Остановка: кнопка **«Выход»** в интерфейсе или Ctrl+C в консоли.

Установка не нужна, интернет не нужен, данные компьютер не покидают.

## Работа

1. **«📂 Открыть ведомость .xlsx»** (или перетащите файл в окно браузера). Нужна ведомость вида
   «Ведомость по остаткам ТМЦ на складах» с помесячными продажами («Октябрь 2023 г.», …).
2. Сразу видны KPI: бюджет закупки, срочные позиции, стоимость и потенциальная прибыль остатков,
   «мёртвые» остатки. Жёлтые плашки — предупреждения о качестве данных исходного файла.
3. **Параметры** (шапка): горизонт (на сколько месяцев закупаем), страховой запас %, срок поставки,
   «нет продаж N мес. → не закупать», флажки «последний месяц неполный» и «учитывать тренд».
   После изменения — **«↻ Пересчитать»**.
4. **Вкладка «Товары и закупка»**: поиск, фильтры (склад/группа/поставщик/статус/ABC), сортировка по
   заголовкам. Клик по «▸» у товара раскрывает график продаж и прогноза и подробный расчёт рекомендации.
   Статусы: 🔴 срочно (продаётся, но остаток 0) · 🟠 к закупке · 🟢 достаточно · 🔵 избыток (>12 мес. запаса) ·
   ⚪ нет продаж за N мес. — не закупать.
5. **Вкладка «Закупка по поставщикам»**: готовые списки заказа по каждому поставщику с суммами.
6. **Вкладка «Аналитика и сезонность»**: индексы сезонности (общие и по группам), продажи по месяцам,
   разрезы по складам/группам/поставщикам, ТОПы по прибыли, упущенным продажам и «мёртвым» остаткам.
7. **Экспорт**: «⬇ Excel с “К закупке”» — книга: ведомость с заполненным столбцом H,
   лист закупки по поставщикам, сезонность и методика. «⬇ CSV закупки» — список заказа для Excel/учёта.

## Что означают цифры

- **К закупке** = прогноз спроса на период (с сезонностью!) + спрос за срок поставки +
  страховой запас − текущий остаток, округление вверх. Товар без продаж за последние N месяцев
  (по умолчанию 12) не заказывается, даже если остаток 0.
- **Розница «оценка»**: в исходном файле розничная цена есть только у товаров с остатком;
  для остальных она оценена по медианной наценке группы (в текущем ассортименте — 50%).
- Подробная методика — файл docs/ALGORITHM.md в репозитории, коротко она также записана
  на листе «Методика» экспортируемого Excel.

## Пакетный режим (без браузера)

```
Ostatki.exe -cli -in "Ведомость.xlsx" -out "Результат.xlsx" -horizon 3 -safety 20 -lead 14
```

GUI с сразу загруженным файлом: `Ostatki.exe -file "Ведомость.xlsx"`.

## Частые вопросы

- **«Не найдена строка заголовков»** — в файле нет колонок «Склад» и «Номенклатура» в первых 20 строках,
  либо это не та выгрузка. **«Не найдены помесячные столбцы»** — в выгрузке нет колонок вида «Октябрь 2023 г.».
- **Порт занят** — приложение само попробует следующие порты (8766, 8767…), адрес смотрите в консоли.
- **Почему закупить 0 у товара с остатком 0?** — у него не было продаж за N месяцев (статус ⚪) или
  прогноз нулевой. Раскройте строку (▸) — там вся арифметика.
- **Суммы «руб.»** — в валюте цен исходного файла (в выгрузке валюта не указана).
