# Руководство по архитектуре проекта для ИИ-агентов и разработчиков (`AGENTS.md`)

Данный документ описывает устройство проекта **«Остатки 2»** (`slchumak75-sketch/Ostatki-2`), в котором сохранены и параллельно собираются **три независимые сборки**:

1. **Сборка «Вариант 3» (актуальная основная сборка, `Latest`)** — пакеты в корне `cmd/ostatki/` и `internal/` + зафиксированный изолированный снапшот в `variants/variant3/`, файлы `Ведомость с периодом ОК (1).xlsx`, `Ведомость с периодом ОК (Вариант 3).xlsx` и 4-листовый отчёт `Заявки поставщикам (авторасчёт).xlsx`.
2. **Сборка «Вариант 2» (сохранённая предыдущая сборка PRO SCM)** — полностью изолированная копия в `variants/variant2/` и файл `Ведомость с периодом ОК (Вариант 2).xlsx`.
3. **Сборка «Вариант 1» (сохранённый базовый эталон)** — полностью изолированная копия в `variants/variant1/` и файл `Ведомость с периодом ОК (Вариант 1).xlsx`.

---

## 1. Ключевые проектные решения «Варианта 3»

1. **Исключено сравнение с предыдущими вариантами:**
   В коде, API, консольном выводе, 4-листовом Excel-отчёте и HTML GUI «Варианта 3» отсутствуют любые расчёты, вкладки, столбцы или фильтры сравнения с «Вариантом 1».
2. **Полное игнорирование красных полей в загружаемом Excel 1С (`internal/xlsx/reader.go`):**
   Парсер `ParseBytes` и `parseWorksheetRows` **полностью игнорируют цвет фона / стили ячеек** (включая красную заливку ячеек в выгрузке 1С). В расчётах и интерфейсе используются исключительно фактические числовые и текстовые значения ячеек.
3. **Структура рабочей таблицы 1-в-1 с исходным Excel 1С (`internal/server/web/index.html`, `internal/server/web/app.js`, `internal/server/web/styles.css`):**
   - `Склад` (столбец `A`), `Группа` (столбец `B`) и `Артикул` (столбец `C`) выведены в отдельные сортируемые столбцы.
   - В столбце `Номенклатура` (столбец `D`) отображается исключительно чистое наименование товара без бейджей и подстрок.
   - В поле ввода столбца 8 (`К закупкам`) полностью отключены стрелки увеличения/уменьшения (`type="text" inputmode="numeric"` + CSS скрытие `spin-button`).
   - Удалены технические столбцы *«Сезон»* и *«Цель»*. Итоговый состав 12 колонок: `Стр.`, `Склад`, `Группа`, `Артикул`, `Номенклатура`, `Сегм.`, `Прод. 12м`, `Остаток`, `Столбец 8: К закупкам`, `Цена`, `Сумма`, `Поставщик`.
4. **Хирургическое сохранение Excel 1С (`WriteOrderColumnLossless`) и фильтрация автопоиска (`discoverDefaultWorkbook`):**
   - Модифицируются только ячейки целевого столбца 8 (`H7..H<N>`) в `xl/worksheets/sheet1.xml` с полным сохранением структуры книги 1С.
   - Автопоиск `discoverDefaultWorkbook()` пропускает служебные файлы с суффиксами `(вариант ...)` и `(к закупкам...)`, всегда открывая основную рабочую ведомость 1С.

## 2. Команды проверки и запуска

```bash
# Полная проверка статического анализатора и всех тестов (все 3 варианта + корень)
go vet ./... && go test -v -race ./...

# Пакетный пересчёт ведомости и 4-листового отчёта «Варианта 3»
go run ./cmd/ostatki -headless \
  -input "Ведомость с периодом ОК (1).xlsx" \
  -inplace \
  -orders-output "Заявки поставщикам (авторасчёт).xlsx"

# Запуск веб-сервера «Вариант 3» для Live Preview (строго на 0.0.0.0)
go run ./cmd/ostatki -server -addr 0.0.0.0:8080 -input "Ведомость с периодом ОК (1).xlsx"
```
