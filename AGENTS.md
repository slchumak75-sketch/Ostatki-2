# Руководство по архитектуре проекта для ИИ-агентов и разработчиков (`AGENTS.md`)

Данный документ описывает устройство проекта **«Остатки 2»** (`slchumak75-sketch/Ostatki-2`), в котором поддерживаются две независимые сборки:
1. **Сборка «Вариант 2» (основная)** — пакеты `cmd/ostatki/` и `internal/`, ведомость `Ведомость с периодом ОК (1).xlsx` и 4-листовый отчёт `Заявки поставщикам (авторасчёт).xlsx`. Сборка **полностью автономна и не содержит никакого сравнения с «Вариантом 1»**.
2. **Сборка «Вариант 1» (архивный эталон)** — полностью изолированная копия в директории `variants/variant1/` и файл `Ведомость с периодом ОК (Вариант 1).xlsx`.

---

## 1. Ключевые требования и проектные решения «Варианта 2»

1. **Исключено сравнение с «Вариантом 1»:**
   В коде, API, консольном выводе, 4-листовом Excel-отчёте и HTML GUI «Варианта 2» отсутствуют любые расчёты, вкладки, столбцы или фильтры сравнения с «Вариантом 1».
2. **Полное игнорирование красных полей в загружаемом Excel 1С (`internal/xlsx/reader.go`):**
   Парсер `ParseBytes` и `parseWorksheetRows` **полностью игнорируют цвет фона / стили ячеек** (включая красную заливку ячеек в выгрузке 1С). В расчётах и интерфейсе используются исключительно фактические числовые и текстовые значения ячеек.
3. **Структура рабочей таблицы 1-в-1 с исходным Excel 1С (`internal/server/web/index.html`, `internal/server/web/app.js`, `internal/server/web/styles.css`):**
   - `Склад` (столбец `A`), `Группа` (столбец `B`) и `Артикул` (столбец `C`) выведены в отдельные сортируемые столбцы.
   - В столбце `Номенклатура` (столбец `D`) отображается исключительно чистое наименование товара без бейджей и подстрок.
   - В поле ввода столбца 8 (`К закупкам`) полностью отключены стрелки увеличения/уменьшения (`type="text" inputmode="numeric"` + CSS скрытие spin-button).
   - Удалены технические столбцы *«Сезон»* и *«Цель»*. Итоговый состав 12 колонок: `Стр.`, `Склад`, `Группа`, `Артикул`, `Номенклатура`, `Сегм.`, `Прод. 12м`, `Остаток`, `Столбец 8: К закупкам`, `Цена`, `Сумма`, `Поставщик`.
4. **Хирургическое сохранение Excel 1С (`WriteOrderColumnLossless`):**
   Модифицируются только ячейки целевого столбца 8 (`H7..H<N>`) в `xl/worksheets/sheet1.xml` с полным сохранением структуры книги 1С.

## 2. Команды проверки и запуска

```bash
# Полная проверка статического анализатора и всех тестов
go vet ./... && go test -v -race ./...

# Пакетный пересчёт ведомости и 4-листового отчёта «Варианта 2»
go run ./cmd/ostatki -headless \
  -input "Ведомость с периодом ОК (1).xlsx" \
  -inplace \
  -orders-output "Заявки поставщикам (авторасчёт).xlsx"

# Запуск веб-сервера для предпросмотра (строго на 0.0.0.0)
go run ./cmd/ostatki -server -addr 0.0.0.0:8080 -input "Ведомость с периодом ОК (1).xlsx"
```
