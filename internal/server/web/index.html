Методика автоматического расчёта столбца 8 «К закупкам»

Алгоритм рассчитывает оптимальное количество к закупке для каждой строки ведомости на основе помесячной статистики продаж (столбцы L..AV) и текущего остатка (столбец G) в 4 этапа:

  1. Нормализация неполного последнего месяца: Из метаданных выгрузки 1С определяется дата отчёта (например, 19.10.2026 = 19 из 31 дня октября, коэффициент 0.613), чтобы незавершённый месяц не занижал оценку осеннего спроса.
  2. Групповые индексы сезонности I(группа, месяц): По каждой товарной группе вычисляется профиль сезонности для всех 12 месяцев года с повышенным весом свежих лет (2026 > 2025 > 2024 > 2023). Например, для «2 краски растворители» летний пик составляет ×1.66, ноябрь — ×0.47, январь — ×0.25.
  3. Гибридный прогноз SKU (Empirical Bayes): Для каждого товара определяется момент ввода в ассортимент, базовый очищенный от сезонности темп продаж B и индивидуальный профиль по одноимённым месяцам прошлых лет. Коэффициент доверия θ = N / (N + K) плавно объединяет личную сезонность ходового товара с надёжным сезонным профилем группы для редких позиций.
  4. Посуточный расчёт на горизонт и вычитание остатка: Суммируется суточный сезонный спрос на Горизонт покрытия + Срок поставки дней, прибавляется Страховой запас %, вычитается Конечный остаток (столбец G) и выполняется округление до целых единиц упаковки.
