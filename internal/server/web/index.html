Сохранить данные перед очисткой ведомости?

«Сохранить» — записать текущую ведомость и свойства номенклатуры, затем очистить ведомость. «Не сохранять» — очистить ведомость без записи. Свойства номенклатуры останутся в памяти программы.

Сохранить текущую ведомость?

При сохранении будут записаны все текущие заказы, фильтры, отметки и настройки.
