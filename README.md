# Остатки 2 — Приложение Windows (Go + HTML GUI) для автозаполнения столбца 8 «К закупкам»

В проекте параллельно поддерживаются и автоматически собираются на GitHub Actions **две независимые сборки** для Windows 10/11 (`x64`, `CGO_ENABLED=0`, единый `.exe` без внешних зависимостей):

| Параметр | Сборка **«Вариант 1»** *(сохранённый эталон)* | Сборка **«Вариант 2»** *(модернизированная PRO SCM)* |
|---|---|---|
| **Исходный код** | [`variants/variant1/`](variants/variant1/) | [`cmd/ostatki/`](cmd/ostatki/), [`internal/`](internal/) |
| **Заполненный Excel ведомости** | `Ведомость с периодом ОК (Вариант 1).xlsx` | `Ведомость с периодом ОК (1).xlsx` |
| **Алгоритм прогноза** | Групповая сезонность + Empirical Bayes по SKU | **Анти-выброс (Winsorization) + ABC×XYZ + Croston/SBA + Адаптивный SLA + Оптимизатор бюджета** |
| **Позиций к закупке** *(30+7 дн.)* | `448 SKU` (`1 882 ед.`) | `400 SKU` (`1 458 ед.`) |
| **Сумма закупки** | `8 525,23 руб.` | **`7 102,89 руб.`** *(экономия оборотных средств **1 422,34 руб.**)* |
| **Управленческий отчёт Excel** | 3 листа (Позиции, Поставщики, Сезонность) | **5 листов** (+ *Неликвиды и избыток*, + *Сравнение Вариант 2 vs 1*) |
| **Артефакт в GitHub Actions / Releases** | **`Вариант 1`** | **`Вариант 2`** |

## Что модернизировано в сборке «Вариант 2»

1. **Подавление разовых оптовых выбросов (`Winsorization`, 108 SKU в базе):**
   В реальной статистике магазинов разовые оптовые/тендерные продажи (например, строка `#1351 Петля гаражная с шар 20*110 б/п` — разовая продажа `1 100 шт.` в ноябре 2023 г. при обычных `2–18 шт./мес.`, или `#1081 Замок почтовый 50 шт.`) завышали розничный заказ в Варианте 1 (`222 шт.` на `628,26 руб.`). В **Варианте 2** такие пики автоматически распознаются, подсвечиваются на графике красным и не искажают ни заказ товара, ни сезонный индекс всей группы.
2. **Матрица `ABC × XYZ` (9 сегментов `AX..CZ`) и метод `Croston / SBA`:**
   Стабильные лидеры продаж (`AX`, `AY`) получают повышенный страховой уровень сервиса (`SLA ×1.25 / ×1.15`), а штучные эпизодические товары класса `Z` рассчитываются по методу Синтетоса–Бойлана (`SBA`) с пониженным страховым буфером.
3. **Оптимизатор лимита бюджета закупки (`Budget Cap`):**
   Позволяет задать жёсткий недельный бюджет (например, `5 000 руб.`), автоматически ранжируя все единицы заказа по индексу приоритета (срочность дефицита, класс `ABC`, рентабельность и сезонность) и укладывая столбец 8 строго в выделенную сумму.
4. **Контроль минимального заказа поставщику и печатный бланк заявки:**
   Автоматически помечает мелкие нерентабельные заказы поставщикам (`< 50 руб.`) и поддерживает печать / экспорт в PDF.
5. **Радар неликвидов и замороженного капитала (`> 365 дней`):**
   Находит `85` позиций со сверхнормативным запасом на сумму **`1 516,96 руб.`** на складах *«Склад Кореличи»* и *«Склад Мир»*.
6. **Встроенная вкладка сравнения «Вариант 2 vs Вариант 1»:**
   Показывает построчно все расхождения обеих сборок с точным объяснением причины по каждому товару.

## Скачивание готовых Windows `.exe` сборок

- **GitHub Releases:** скачайте готовые релизы **`Вариант 1`** или **`Вариант 2`** на вкладке **Releases** репозитория.
- **GitHub Actions:** при каждом `push` / `pull_request` workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) параллельно собирает и публикует два артефакта:
  - **`Вариант 1`** (`OstatkiZakupki_Вариант_1.exe`, `OstatkiZakupki_Вариант_1_cli.exe`, `.bat`, ведомость v1)
  - **`Вариант 2`** (`OstatkiZakupki_Вариант_2.exe`, `OstatkiZakupki_Вариант_2_cli.exe`, `.bat`, ведомость v2, 5-листовый отчёт)

## Сборка обеих версий из исходников

```bash
# Прогнать все тесты одновременно для Варианта 1 и Варианта 2
go test -v -race ./...

# Собрать Windows GUI приложение «Вариант 1»
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" \
  -o OstatkiZakupki_Вариант_1.exe ./variants/variant1/cmd/ostatki

# Собрать Windows GUI приложение «Вариант 2»
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" \
  -o OstatkiZakupki_Вариант_2.exe ./cmd/ostatki
```
