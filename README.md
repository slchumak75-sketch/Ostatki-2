# Ostatki-2 — остатки, прибыльность и «К закупке» по сезонности

Приложение для Windows (**Ostatki.exe**, Go + HTML GUI) анализирует «Ведомость по остаткам ТМЦ на
складах» из 1С: считает прибыльность, сезонность спроса и заполняет пустой **столбец H (8-й)**
ведомости рекомендацией **«К закупке»** — сколько каждого товара заказать на выбранный период.

## Быстрый старт

1. Скачайте `Ostatki-windows-amd64.zip`: вкладка **Actions** → последний запуск **Build Windows** →
   Artifacts (или со страницы Releases, если есть тег `v*`).
2. Распакуйте, запустите `Ostatki.exe` — откроется браузер с интерфейсом (консоль не закрывать).
3. Откройте свою ведомость `.xlsx`, настройте параметры, скачайте Excel с «К закупке».

Подробно: [docs/USER_GUIDE.md](docs/USER_GUIDE.md). Сборка из исходников и CI: [docs/BUILD.md](docs/BUILD.md).

## Что посчитано по текущему файлу (2026-10-20)

Исходник: `Ведомость с периодом ОК (1).xlsx` — 1850 товаров, 2 склада, продажи помесячно окт 2023 — окт 2026.

- **Прибыльность**: средняя маржа 33,6%, медианная наценка 50%; остатки — 29 686 руб. по закупке /
  44 367 руб. по рознице (потенциальная прибыль 14 681 руб.). Краски дают ~75% валовой прибыли.
- **Сезонность**: январь 0,40 → июль 1,51 (у красок 0,25 → 1,65). Без сезонных индексов закупка бессмысленна.
- **К закупке** (горизонт: остаток окт 2026 + ноя 2026 — янв 2027, страховой запас 20%, поставка 14 дней):
  **765 SKU · 4138 ед. · бюджет 21 037 руб.**; 573 позиции продаются при нулевом остатке (срочно),
  175 позиций на остатке не продаются год (заморожено 4190 руб.).

Полный разбор: [docs/ANALYSIS.md](docs/ANALYSIS.md) · формулы: [docs/ALGORITHM.md](docs/ALGORITHM.md) ·
готовый файл с заполненным столбцом H: [output/Ведомость_К_закупке.xlsx](output/Ведомость_К_закупке.xlsx).

## Как устроено

```
cmd/ostatki/        точка входа exe: GUI (веб-сервер 127.0.0.1 + браузер) и CLI-режим
internal/forecast/  алгоритм «К закупке» с сезонностью (+ тесты)
internal/xlsxio/    чтение ведомости 1С и генерация итогового XLSX — только stdlib
internal/app/       HTTP API и встроенный HTML/CSS/JS интерфейс (web/)
tools/              Python: эталонный алгоритм, анализ, заполнение H в оригинале, dev-сервер
docs/               вся документация (включая передачу дел следующему агенту)
output/             готовый Excel с «К закупке» по исходному файлу
.github/workflows/  автосборка Windows exe при каждом push; Release по тегу v*
```

Приложение офлайн, без внешних зависимостей и установки: один exe. Данные никуда не отправляются.
