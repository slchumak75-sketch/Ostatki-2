# Остатки 2 — Автозаполнение столбца 8 «К закупкам» и приложение для Windows (Go + HTML GUI)

Настольное приложение для **Windows 10 / 11** на языке **Go** (без внешних зависимостей, единый `.exe`-файл со встроенным русскоязычным **HTML GUI**) и пакетная обработка для автоматического расчёта **Столбца 8 (`H` — «К закупкам»)** в выгрузках 1С *«Ведомость по остаткам ТМЦ на складах»* на основании многолетней помесячной статистики продаж.

---

## Что сделано по исходному файлу Excel в репозитории

В репозитории проанализирован и обработан файл **`Ведомость с периодом ОК (1).xlsx`**:
- **Масштаб данных:** `1 850` товарных позиций (`Склад Кореличи` — 785 SKU, `Склад Мир` — 1 065 SKU), `34` поставщика, `37` месяцев статистики продаж (`Октябрь 2023 г.` — `Октябрь 2026 г.`, столбцы `L..AV`).
- **Столбец 8 (`H`):** автоматически заполнен заголовком **`К закупкам`** (`H7`) и расчётными целочисленными объёмами закупки (`H8:H1857`) при сохранении **100% оригинального форматирования 1С** (палитра `indexedColors`, красная подсветка минимальных остатков в столбце `G`, рамки, шрифты `Arial`, кнопки `Обновить` и `Настройка` в `drawing1.xml`).
- **Сводный результат базового сценария** *(горизонт 30 дн. + 7 дн. поставка, страховой запас 20%, срез от 19.10.2026)*:
  - Позиций к закупке: **448 из 1 850 SKU (24,2%)**
  - Итого единиц в столбце 8: **1 882 ед.**
  - Бюджет закупки в ценах поставщиков: **8 525,23 руб.** *(экономия оборотных средств на осенне-зимнем спаде по сравнению с наивным средним без учёта сезонности!)*
  - Ожидаемая розничная стоимость партии: **12 774,94 руб.** *(валовая маржа **+4 249,71 руб.**)*
- Дополнительно сформирован готовый 3-листовый отчёт **`Заявки поставщикам (авторасчёт).xlsx`** с разбивкой заказов по поставщикам и складам.

## Ключевые возможности приложения Windows (`OstatkiZakupki.exe`)

1. **Автономный `.exe` без установки:** весь HTML/CSS/JS интерфейс встроен внутрь Go-бинарника (`embed.FS`). Работает **полностью оффлайн** (без интернета) на любом ПК с Windows 10/11.
2. **Нативное окно приложения (App Mode):** запускается без чёрного консольного окна в отдельном окне Microsoft Edge / Chrome `--app` без адресной строки и вкладок, автоматически завершая фоновый процесс при закрытии окна.
3. **Сезонно-трендовая модель (Empirical Bayes):**
   - Автоматический учёт **неполного последнего месяца** по дате выгрузки из метаданных Excel (`19.10.2026` → `19/31` дня октября).
   - Вычисление **12-месячных индексов сезонности** по каждой группе номенклатуры (например, *«2 краски растворители»*: июль `×1.66`, ноябрь `×0.47`, январь `×0.25`; *«2 замки фурнитура»*: июль `×1.48`, январь `×0.47`).
   - Корректная обработка **новинок** (активное окно от первой продажи, а не деление на 37 месяцев) и **выведенных из ассортимента позиций** (повышенный вес свежих лет `2026 > 2025 > 2024 > 2023`).
   - Плавное байесовское объединение индивидуальной сезонности ходовых SKU с групповым профилем для товаров с редким спросом.
4. **Интерактивная работа закупщика:**
   - Быстрые пресеты (*14 дней*, *Стандарт 30+7 дней*, *2 месяца*, *Квартал*, *Подготовка к весне*) и тонкая настройка всех параметров в реальном времени.
   - Поиск и фильтрация по **складу**, **группе**, **поставщику**, **ABC-классу**, **красной метке 1С**, **нулевому остатку**.
   - **Ручная корректировка** любой ячейки столбца 8 прямо в таблице с мгновенным пересчётом бюджета.
   - **Карточка товара с графиками** фактических продаж за 37 месяцев, 12-месячной кривой прогноза и текстовым обоснованием каждой цифры.
   - **Lossless-сохранение** прямо в исходный `.xlsx` или скачивание заполненной ведомости + персональных Excel-заявок для любого из 34 поставщиков.

## Где скачать готовый `.exe` (GitHub Actions)

При каждом `push` или `pull_request` автоматически запускается workflow [`.github/workflows/build.yml`](.github/workflows/build.yml):
1. Откройте вкладку **Actions** на GitHub → выберите последний зелёный запуск **Build Windows App (Go + HTML GUI)**.
2. В блоке **Artifacts** скачайте:
   - **`OstatkiZakupki-Windows-x64-exe`** — одиночный исполняемый файл `OstatkiZakupki.exe`;
   - или **`Ostatki-2-Windows-x64-Bundle`** — полный архив с `OstatkiZakupki.exe`, `OstatkiZakupki-cli.exe`, `.bat`-ярлыками и заполненной ведомостью.
3. Положите `OstatkiZakupki.exe` в папку с файлом ведомости Excel (или просто запустите и перетащите любой `.xlsx` мышкой в окно программы).

## Режимы запуска и интеграция с 1С (CLI)

### 1. Графический режим на Windows (по умолчанию)
Двойной клик по `OstatkiZakupki.exe` (или перетаскивание файла `.xlsx` на иконку `OstatkiZakupki.exe` в Проводнике Windows).

### 2. Пакетный безголовый режим (`-headless`) для 1С и `.bat` скриптов
```bat
REM Заполнить столбец 8 прямо в исходном файле + выгрузить сводные заявки поставщикам:
OstatkiZakupki-cli.exe -headless -input "Ведомость с периодом ОК (1).xlsx" -inplace -orders-output "Заявки поставщикам.xlsx"

REM Расчёт с кастомным горизонтом 45 дней, поставкой 5 дней и страховым запасом 25%:
OstatkiZakupki-cli.exe -headless -input "Ведомость.xlsx" -output "Ведомость_готово.xlsx" -horizon 45 -lead 5 -safety 25
```

### 3. Веб-серверный режим в локальной сети магазина
```bash
./ostatki -server -addr 0.0.0.0:8080
```

## Самостоятельная сборка из исходного кода

Проект использует **только стандартную библиотеку Go 1.24+** (`CGO_ENABLED=0`, 0 внешних зависимостей):

```bash
# Запуск всех тестов (включая проверку lossless-записи на реальном файле Excel)
go test -v -race ./...

# Сборка десктопного приложения для Windows x64 (без консольного окна)
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" -o OstatkiZakupki.exe ./cmd/ostatki

# Сборка консольной утилиты для Windows x64
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o OstatkiZakupki-cli.exe ./cmd/ostatki
```
