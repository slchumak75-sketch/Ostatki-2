# Остатки 2 — Приложение Windows (Go + HTML GUI) для автозаполнения столбца 8 «К закупкам»

В проекте параллельно поддерживаются и автоматически собираются на GitHub Actions **две независимые сборки** для Windows 10/11 (`x64`, `CGO_ENABLED=0`, единый `.exe` без внешних зависимостей):

- **Сборка «Вариант 2» (основная, PRO SCM):** расположена в `cmd/ostatki/` и `internal/` (`Ведомость с периодом ОК (1).xlsx`, `Заявки поставщикам (авторасчёт).xlsx`).
- **Сборка «Вариант 1» (сохранённый архивный эталон):** изолирована в `variants/variant1/` (`Ведомость с периодом ОК (Вариант 1).xlsx`).

---

## Возможности сборки «Вариант 2»

1. **Полное игнорирование цветовой раскраски (красных полей) в загружаемых файлах 1С Excel:**
   При чтении ведомости парсер анализирует исключительно фактические числовые значения остатков и продаж, полностью игнорируя старую красную заливку ячеек из 1С.
2. **Подавление разовых оптовых выбросов (`Winsorization`, 108 SKU в базе):**
   Разовые оптовые/тендерные отгрузки (например, `#1351 Петля гаражная с шар 20*110 б/п` — разовая продажа `1 100 шт.` в ноябре 2023 г. при обычных `2–18 шт./мес.`) автоматически сглаживаются, подсвечиваются на графике и не завышают розничный заказ.
3. **Матрица `ABC × XYZ` (`AX..CZ`) и метод `Croston / SBA`:**
   Стабильные лидеры продаж (`AX`, `AY`) получают повышенный страховой уровень сервиса (`SLA ×1.25 / ×1.15`), а штучные эпизодические товары класса `Z` рассчитываются по методу Синтетоса–Бойлана (`SBA`).
4. **Оптимизатор лимита бюджета закупки (`Budget Cap`):**
   Автоматически ранжирует единицы заказа по индексу приоритета и укладывает столбец 8 строго в заданный бюджет недели.
5. **Рабочая таблица 1-в-1 со структурой ведомости 1С и 4-листовый отчёт Excel:**
   - **Раздельные колонки:** `Стр.`, `Склад`, `Группа`, `Артикул` (из столбца `C` исходного Excel), `Номенклатура` (строго чистое наименование товара без лишней информации, как в исходном Excel), `Сегм.`, `Прод. 12м`, `Остаток`, `Столбец 8: К закупкам` (чистое числовое поле ввода без стрелок вверх/вниз), `Цена`, `Сумма`, `Поставщик`.
   - Отчёт `Заявки поставщикам (авторасчёт).xlsx` содержит 4 листа: *К закупкам (Вариант 2)*, *По поставщикам*, *Сезонность и ABC-XYZ*, *Неликвиды и избыток*.

## Скачивание готовых Windows `.exe` сборок

- **GitHub Releases:** скачайте готовые релизы **`Вариант 2`** (актуальная версия) или **`Вариант 1`** на вкладке **Releases** репозитория.
- **GitHub Actions:** при каждом `push` / `pull_request` workflow [`.github/workflows/build.yml`](.github/workflows/build.yml) параллельно собирает и публикует оба артефакта (**`Вариант 1`** и **`Вариант 2`**).

## Сборка из исходников

```bash
# Прогнать все тесты
go test -v -race ./...

# Собрать Windows GUI приложение «Вариант 2»
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" \
  -o OstatkiZakupki_Вариант_2.exe ./cmd/ostatki

# Собрать Windows GUI приложение «Вариант 1»
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-s -w -H=windowsgui" \
  -o OstatkiZakupki_Вариант_1.exe ./variants/variant1/cmd/ostatki
```
