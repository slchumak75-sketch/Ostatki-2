## Вариант 5: ручной эталон номенклатуры

В панели **«Параметры»** добавлены **«Сохранить эталон Номенклатуры»**, **«Выгрузить эталон Номенклатуры (Excel)»** и **«Загрузить эталон Номенклатуры»**.

- Единые поля Excel, JSON и сохранённого каталога: **Склад, Артикул, Номенклатура, + (галочка), Рейтинг, Остаток**. В Excel — ровно шесть видимых столбцов с фильтрами. Скрытый служебный лист сохраняет идентичность старых товаров без артикула; редактировать его не нужно.
- **Сохранение эталона — только вручную**, при открытой ведомости 1С. В эталон попадает вся текущая база по всем складам, независимо от фильтра и видимых строк. **«Сохранить эталон Номенклатуры»** записывает эталон в программу, без автоматического скачивания; создаётся также локальная копия **`Эталон, ДД.ММ.ГГГГ.xlsx`**. Для скачивания сохранённого снимка предусмотрена отдельная кнопка **«Выгрузить эталон Номенклатуры (Excel)»**. Выгрузка не обновляет эталон и сохраняет исходную дату его сохранения. Повторное ручное сохранение в тот же день заменяет одноимённый файл.
- Рейтинг для позиций эталона **фиксируется как текущее значение**. После загрузки новой ведомости и перезапуска он не пересчитывается на экране. Новые позиции, которых нет в эталоне, получают обычный расчётный рейтинг.
- **Рейтинг и остаток эталона в программе и файле фиксируются на момент ручного сохранения** и не меняются при загрузке новых ведомостей, автосохранении или выходе. **В рабочей ведомости остаток всегда берётся из новой 1С**, не подменяется старым остатком из эталона. Продажи, месячные графики, расчёт заказов и бюджета не меняются из-за фиксации отображаемого рейтинга.
- Загрузка эталона применяет его галочки и фиксированный рейтинг по складу и артикулу (для товаров без артикула — по группе/наименованию и складу). Обычный импорт свойств применяет галочки, но не заменяет живые данные 1С.
- Изменение галочек, автосохранение базы, обычное сохранение свойств и выход **никогда не перезаписывают эталон**. Рабочие галочки сохраняются отдельно, как и раньше.
- Старые пятиколоночные Excel-файлы и JSON-копии галочек загружаются через обычную кнопку свойств. Для кнопки загрузки **эталона** требуется новый формат с рейтингом.
- Каталог Варианта 5 хранится отдельно: `%APPDATA%/Ostatki2/properties-v5` (Windows). При первом запуске отметки читаются из старого каталога Варианта 4 **без изменения его файлов**. Папка сохранения показывается в панели параметров.

## Сравнение с эталоном и фильтры

- В «Параметрах» кнопки расположены двумя рядами: свойства (выгрузка, загрузка, сохранение, JSON-копия); эталон (сохранение, загрузка, выгрузка, сравнение) и «Сохранить поля».
- «Сравнить с эталоном» показывает объединение двух условий: **текущая галочка + рост остатка** либо **рейтинг эталона 1 → текущий расчётный рейтинг 0**. Второе условие не зависит от галочки. Сопоставление — по складу и артикулу, с прежним резервным ключом для товаров без артикула. Незнакомые эталону позиции не включаются.
- Для сравнения берётся настоящий расчётный рейтинг новой базы, а не фиксированный рейтинг отображения. В сравнении отображается именно этот текущий рейтинг. Эталон, заказы и общий бюджет сравнение не изменяет.
- В режиме сравнения обычные фильтры временно не применяются, иначе активный фильтр «Актуально» скрыл бы помеченные позиции. Нажатие **любой вкладки**, включая уже активную «Ведомость», завершает сравнение и возвращает обычные фильтры. Новая загрузка и очистка базы также завершают сравнение.
- «Продажи 12 мес.» и «Актуально» вынесены на верхнюю плашку и по умолчанию включены. Отключение каждого — четвёртым нажатием; повторное включение — одним нажатием. Сброс обычных фильтров эти кнопки не отключает.
- Строки состояния эталона и свойств показывают только имя последней сохранённой версии и дату/время записи в программу, без пути к папке. Метаданные сохраняются после перезапуска; время загрузки эталона в программу хранится отдельно от исходной даты его файла.

## Унаследованные возможности PRO SCM

1. **Чистый и плотно скомпонованный интерфейс закупщика сразу в полноэкранном режиме:**
   - На Windows программа открывается **сразу в полноэкранном режиме** (`--start-fullscreen` + `SW_SHOWMAXIMIZED` с кнопками переключения режима окна **`⛶`** и закрытия **`✕`** в правом верхнем углу), а сборка содержит встроенные PE-ресурсы (`asInvoker`, иконку, `VERSIONINFO`) и цифровую подпись Authenticode `SHA-256`.
   - Блок **«Бюджет закупки»** расположен на одном горизонтальном уровне с переключателями **«Режим планирования»**, а лишние блоки (*«Столбец 8 «К закупкам»»*, *«Округление и заголовок H7»* / *«К закупкам»*) убраны.
   - Параметры **«Покрытие запаса (дней)»** (`30`), **«Срок поставки (дней):»** (**`4`** дня по умолчанию) и **«Базовый страх. запас: (%)»** (**`10%`** по умолчанию) вводятся в числовых окошках (`<input type="number">`).
   - Боковая правая панель с графиками и вкладка *«Матрица ABC×XYZ и Сезонность»* убраны — рабочая таблица занимает 100% ширины окна.
2. **Рабочая таблица 1-в-1 со структурой ведомости 1С со всеми строками на экране (13 столбцов):**
   - Отображаются **сразу все строки номенклатуры** без постраничной разбивки; при вертикальном скроллинге **горизонтальная панель фильтров** (*«Все склады»*, *«Все группы»*, расширенное на 50% поле *«Все поставщики»*) и **шапка таблицы номенклатуры** поднимаются вверх, закрепляются вверху экрана и всегда остаются видимыми.
   - При ручной корректировке количества в поле **«Заказ»** старое значение автоматически очищается при вводе новых цифр.
   - горизонтальная плашка над таблицей **«Ведомость»** со строгой последовательностью полей (**Все склады → Все группы → Поиск артикул → Поиск по номенклатуре → Рейтинг: Все → Все поставщики → Показать все строки**), эталонной шириной столбцов по умолчанию (с возможностью ручной подстройки мышью `.col-resizer`, двойной клик — сброс) и **выбором поставщиков галочками** в списке **«Все поставщики»** для суммирования **«Бюджета закупки»**, присвоения статуса **«Готов к отправке»** и формирования Excel-файлов;
   - 13 сортируемых колонок: `Склад`, `Группа`, `Артикул`, чистое наименование `Номенклатуры`, **`Ед.`** (`шт.` во всех строках), **`Рейтинг`** (чёрные цифры `5`..`0` в маленьких цветных кружочках: `5` ярко-зелёный, `4` салатовый, `3` ярко-жёлтый, `2` бледно-жёлтый, `1` розовый, `0` ярко-красный — при наведении курсора на цифру рейтинга справа всплывает окно с помесячным графиком продаж за последние 3 года), `Продажи`, `Остаток`, `Заказ`, `Цена`, **`Розница`** (из столбца *«Розничная цена»* исходного файла Excel сразу после столбца *«Цена»*), **`Сумма`** (строго равна произведению граф **«Заказ» × «Цена»** во всех строках с мгновенным живым пересчётом при вводе), `Поставщик`; панель **«Параметры PRO SCM»** при запуске программы по умолчанию свёрнута, строки таблицы ужаты по высоте (`padding: 1px 6px`, поле ввода `height: 18px`).
   - **Светло-салатовая подсветка строк** номенклатуры (`#e2f9df`), по которым устанавливается автоматический заказ (`autoOrderQty > 0`).
   - Столбцы **`Склад`** и **`Группа`** оформлены в **однострочном** виде с увеличенным читаемым шрифтом (`11.5px`), а во вкладке *«Радар замороженного капитала и неликвидов»* столбцы идут в едином порядке **`Продажи` → `Остаток`**.
   - В реестре заказов по поставщикам кнопка **`Заказ .xlsx`** формирует индивидуальную неокрашенную заявку с именем **`<Наименование склада>, <Наименование поставщика>, <текущая дата>.xlsx`** и ровно 5 столбцами (`Наименование склада`, `Артикул`, `Номенклатура`, `Ед.` со значением `шт.`, `Заказ`).
   - Столбцы **`Продажи`** и **`Остаток`** оформлены единым обычным чёрным шрифтом без цветовой подсветки нулей; столбцы **`Продажи`**, **`Остаток`** и **`Заказ`** зафиксированы на ширину пяти цифровых символов с разделителем групп разрядов (`99 999`, `tabular-nums`, без стрелок прокрутки).
3. **Точный расчёт PRO SCM без искажений:**
   - Полное игнорирование старых красных ячеек из выгрузки 1С, подавление разовых оптовых выбросов (`Winsorization`), матрица `ABC × XYZ`, метод `Croston / SBA` для редких `Z`-товаров, лимит бюджета и 4-листовый отчёт Excel (`359 SKU`, `1 178 ед.`, `5 704,18 руб.`).

### Папки сохранения актуального Варианта 5

В настольной программе ведомости (в том числе автоматические сохранения) сохраняются
в **Загрузки/Ведомость**; выгрузка свойств XLSX и резервные копии JSON — в
**Загрузки/Номенклатура**; выгрузка сохранённого эталона — в **Загрузки/Эталон**.
Windows-папка «Загрузки» определяется системным API, включая перенаправление на другой диск.
Внутреннее независимое хранилище свойств и эталона не меняется.
Старые ведомости не перемещаются: открыть их можно через выбор файла;
список сохранённых ведомостей показывает новую папку.
В браузерном режиме расположение скачиваний задаёт браузер.
Если сервер недоступен, резервная копия JSON скачивается из памяти через браузер:
для неё выберите «Номенклатура» вручную, о резервном способе программа предупреждает.

Крестик основной панели заменён кнопкой «Закрыть программу» в Параметрах;
подтверждение сохранения перед выходом сохранено. Поля параметров уменьшены до 2/3.

Предупреждение SmartScreen «Система Windows защитила ваш компьютер» не устраняется
самоподписанным сертификатом. Не отключайте защиту Windows. Доверенная подпись издателя
и репутация приложения уменьшают вероятность предупреждения, но не гарантируют
его отсутствие для новой сборки.

### Повторная загрузка и сравнение с эталоном

При явном сохранении нового эталона записываются **расчётные рейтинги текущей
ведомости**, а не зафиксированные рейтинги предыдущего эталона. Повторяющиеся
строки одного товара сохраняют отдельные остатки и рейтинги в служебных данных;
видимые шесть столбцов XLSX и правила галочек не изменяются. Служебные данные
сохраняются при выгрузке/загрузке эталона и перезапуске программы.
У полностью одинаковых строк без уникального артикула сопоставление выполняется
по порядку повторений внутри одинаковых группы, наименования и склада.

Если эталон был сохранён старой версией, заново загрузите исходную ведомость и
один раз нажмите «Сохранить эталон Номенклатуры»: утраченные отдельные строки
в старом снимке автоматически восстановить невозможно. Не пересохраняйте эталон
по новой ведомости, если требуется сравнить её с историческим состоянием.
