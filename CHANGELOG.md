## 2026-10-20 — приложение Ostatki v1 (ветка arena/2b3ecebf-ostatki-2)

- **Анализ**: разобран исходный `Ведомость с периодом ОК (1).xlsx` (1850 SKU, 37 месяцев продаж).
  Прибыльность: средняя маржа 33,6%, медианная наценка 50%; остатки 29 686 руб. по закупке /
  44 367 по рознице; найдены дефекты данных («Расход»≠сумме месяцев у 828 строк, розница только
  при остатке>0, 2 позиции с отрицательной маржой и др.). Подробно: docs/ANALYSIS.md.
- **Столбец H (8) «К закупке»**: спроектирован сезонный алгоритм (индексы сезонности со сглаживанием
  товар→группа, базовый уровень за 12 мес., затухающий тренд, срок поставки, страховой запас,
  защита «нет продаж 12 мес.»). По умолчанию: 765 SKU, 4138 ед., бюджет 21 036,70 на остаток
  октября + ноябрь 2026 — январь 2027. Формулы: docs/ALGORITHM.md.
- **Готовый Excel**: `output/Ведомость_К_закупке.xlsx` — копия оригинала с заполненным H и листами
  «Закупка по поставщикам», «Сезонность», «Методика» (генератор: tools/fill_purchase.py).
- **Приложение Windows на Go**: Ostatki.exe — локальный HTTP-сервер (127.0.0.1) + встроенный HTML GUI,
  парсер и генератор XLSX на стандартной библиотеке, CLI-режим, юнит-тесты. GUI: KPI, параметры,
  таблица со статусами и детализацией расчёта, закупка по поставщикам, аналитика и графики сезонности,
  экспорт Excel/CSV.
- **CI/CD**: GitHub Actions (`.github/workflows/build-windows.yml`) — автосборка при push/PR:
  vet, тесты, сборка windows/amd64, smoke-тест на реальной ведомости, zip-артефакт; по тегу `v*` — Release.
- **Инструменты разработки**: эталонный Python-алгоритм и dev-сервер с тем же API (`tools/`),
  чтобы GUI можно было развивать без Go и сверять реализации.
- **Документация**: README, docs/ANALYSIS/ALGORITHM/ARCHITECTURE/BUILD/USER_GUIDE/AGENT_HANDOFF.
