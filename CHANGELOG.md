# CHANGELOG.md — История изменений проекта `Ostatki-2`

## [1.0.0] — 2026-10-20

### Анализ и обработка исходного Excel-файла
- Проведён полный структурный, статистический и XML-аудит файла **`Ведомость с периодом ОК (1).xlsx`** (`1 857` строк, `48` столбцов `A..AV`, `1 850` товарных позиций по складам *«Склад Кореличи»* и *«Склад Мир»*, `34` поставщика, `37` помесячных столбцов с `Октября 2023 г.` по `Октябрь 2026 г.`).
- Выявлены и учтены критически важные особенности данных выгрузки 1С:
  1. **Неполный последний месяц:** по метаданным `docProps/core.xml` (`2026-10-19T20:43:37Z`) выгрузка сформирована `19.10.2026`, поэтому столбец `AV` (`Октябрь 2026 г.`) нормируется с коэффициентом полноты `19/31 ≈ 0.6129`.
  2. **Многострочные розничные цены партий в 1С:** обнаружены ячейки `J1317` (`"7.00\n9.72"`) и `J1793` (`"16.00\n22.14"`), а также пустые розничные цены при нулевом остатке — реализован безопасный парсер актуальной партии `ParseFlexibleFloat` и медианная оценка групповой наценки (`~1.50`).
  3. **Красная подсветка дефицита 1С (`style="14"` в столбце `G`):** распознана и выведена в UI (`842` позиции) вместе с сохранением оригинальной палитры `indexedColors` и кнопок `xl/drawings/drawing1.xml`.
- Выполнен автоматический расчёт и заполнение **Столбца 8 (`H` — «К закупкам»)** непосредственно в `Ведомость с периодом ОК (1).xlsx` + сформирован 3-листовый отчёт `Заявки поставщикам (авторасчёт).xlsx`.

### Разработка Windows-приложения на Go с HTML GUI
- Создан модульный Go-проект (`go 1.24`, **0 внешних зависимостей**, `CGO_ENABLED=0`):
  - `internal/xlsx`: потоковый парсер `.xlsx` и высокоскоростной (`~5 мс`) `O(N)` lossless-райтер столбца 8 + генератор Excel-заявок поставщикам.
  - `internal/forecast`: иерархический сезонно-трендовый движок (Empirical Bayes: групповые сезонные индексы + индивидуальная сезонность SKU + активное окно новинок + ABC-анализ).
  - `internal/server` + `internal/server/web`: встроенный через `embed.FS` русскоязычный HTML GUI с KPI-дашбордом, интерактивными параметрами и пресетами, фильтрацией, ручным редактированием столбца 8, карточкой товара с 37-месячным и 12-месячным SVG-графиками, аналитикой сезонности и реестром поставщиков.
  - `internal/desktop`: нативный запуск отдельного окна Windows (Microsoft Edge / Chrome `--app`) с автоматическим завершением процесса при закрытии окна.
  - `cmd/ostatki`: поддержка десктопного GUI, пакетного CLI (`-headless`) для интеграции с 1С и сетевого `-server` режима.
